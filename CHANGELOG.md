# Changelog

## 1.0.0

- Added a unified async-first agent engine with explicit run lifecycle states.
- Added native multi-tool-call execution with provider tool-call ID association.
- Added capability-based permissions, practical JSON Schema validation, structured failures, and non-zero shell exit handling.
- Added SQLite run records and checkpoints.
- Added the isolated offline repository-maintenance demonstration and v1 architecture, security, development, walkthrough, and demo documentation.
- Removed CLI pseudo-streaming of already-completed answers. Provider streaming remains available through the LLM API.

## 0.4.0

- Added runtime hardening, trace utilities, adapters, memory extensions, and CI.
